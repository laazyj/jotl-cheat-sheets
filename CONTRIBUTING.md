# Contributing

Thanks for looking, but this is a personal project — a cheat-sheet set made
for one gaming group and published here for reference and posterity.

**Contributions are not accepted.** Please don't open pull requests; they will
be closed. Issues and feature requests aren't monitored either.

If you spot a genuine rules error on one of the sheets, you're welcome to note
it, but there's no promise it will be actioned or on any timeline.

You're free to read, print, share, and adapt the sheets for your own
non-commercial use under [`LICENSE`](LICENSE) (CC BY-NC-SA 4.0). Note that the
underlying game rules and imagery remain the property of Cephalofair Games and
are not relicensed by this project.
